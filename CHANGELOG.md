## [0.1.0-alpha] - 2026-09-22

### Added
- Schedule (agenda / week / month), swaps, timesheet, team, audit
- Admin organization labor rules + offline backup settings
- First-run `/setup` wizard and forced password change for new staff
- Windows desktop shell (Electron) with local AppData Postgres
- Nightly JSON backup to local + OneDrive/Google Drive sync folder
- GitHub Actions release pipeline for Windows `.exe` + release notes

### Docs
- Digital getting-started preference (Web vs Desktop)
- Deployment, user guide, Windows desktop, release guides
